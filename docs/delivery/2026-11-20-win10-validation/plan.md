只读检查：根 AGENTS、执行端说明、现场手册、现有构建产物和原打包验证记录。当前仍不是 Git 仓库，Git 状态查询退出 1。wheel SHA-256 与上一轮实测记录一致；sdist 包含锁文件、原生/运行/窗口测试及离线页面。

范围：新增本目录说明与空白记录，在忽略的 `dist/` 生成可复制 ZIP；现场手册补充用户确认。复用现有 wheel、sdist、示例和锁定依赖清单，不重新开发安装器、不下载业务环境或修改系统配置。
