## 3 发现、修订与残余风险

独立复核提出两项文档问题，主 agent 已核验并修改，独立 agent 重新读取后确认均已关闭；未发现已证实的文档 P0/P1：

- P2：环境准备占用维护槽，但缺少安装卡住、取消和重启后的处理。主方案第 9.2 节增加独立操作 ID、命令去重、账本与进程监督、总时限、停止确认及恢复核对；M3 增加对应验收。
- P3：PostgreSQL 支持版本链接指向锁文档。已换为官方版本支持政策并核对 PostgreSQL 17 状态。

未验证及风险：

1. 当前 Playwright 官方要求不含 Windows 10；两台机器的 edition/build、支持渠道和既有脚本兼容性未盘点。Session 0 不能代替交互会话执行，锁屏/RDP/注销和重启均需实机 POC。
2. Job Object 进程树、未知运行核对、准备失败恢复及业务副作用均只有设计，未执行真实故障测试，不能据本文宣布可靠性完成。
3. 部分仓库 API 因 403 限流未取得 pushed_at/archived/SPDX，来源与空值已标明；Star 不代表安全或维护承诺。钉钉官方接入页正文未能读取，本轮未冻结加签、频率和长度细节。
4. 具体补丁版本、锁文件、全量依赖许可、安全扫描、权限矩阵、补跑规则、保留期、容量、备份目标和部署环境尚未冻结；Q01–Q12 保留相应门禁。
5. 单云主机是单点；未来发布与回滚、数据库恢复和脚本迁移均需演练，不能同时开启旧脚本定时和中台计划。

本轮没有可发布产品或生产回滚动作。文档撤回不会改变现有脚本运行；后续实际系统的回滚边界已写入主方案及 ADR。
