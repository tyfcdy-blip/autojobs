# 本机执行端状态窗口

本目录为 M0 的只读 Vue 窗口，配套 Python pywebview 宿主。状态来自本机执行端，不内置演示数据，不直接连接中台，不提供脚本运行、停止、环境安装或机器人配置功能。关闭窗口不持有或结束 worker。

## 设计与边界

延续已确认的 `05-local-runner.png`：浅灰工作区、白色内容、青绿色强调，中文办公工具。展示距离以桌面窗口为主；层级为本机状态、当前任务、最近运行和结果详情。字号 14/16/22/30，使用系统微软雅黑及 Segoe UI；8 像素间距基准；边框半径 8/12；仅按钮和状态采用 160ms 反馈，不增加动画面板或无关控件。

窗口唯一桥接口为 `window.pywebview.api.get_status()`。初始化支持桥已存在或 `pywebviewready` 事件；每次读取完成后等待两秒再读，最多一个在途请求。读取超时会提示重新打开窗口，不并发请求绕过未完成读取。关闭组件清理事件与计时器，迟到响应不会继续刷新界面。读取失败保留历史快照并明确标注状态待确认；不能由旧心跳推断当前在线。

建议宿主默认 1120×780，最小 720×560。页面也适配较窄窗口，不要求虚构设备名称、系统版本或中台连接。

## 开发与验证计划

模式：全过程开发；本工作包 L2（Vue/Python 桥接状态），整体 M0 风险等级由主任务计划管理。初始无前端实现、无 Git 仓库。写入仅此目录和指定 `desktop_assets` 生成目录；不修改宿主、账本或进程模块。

| 用例 | 输入/边界 | 预期 |
| --- | --- | --- |
| UI-01 | 桥未就绪及尚未返回 | 明确连接/读取状态，不显示假任务 |
| UI-02 | 无任务，worker离线/在线 | 真实空状态；在线与空闲分开 |
| UI-03 | running/reconciling、已停止和失败等状态 | 中文状态正确，待核实不显示空闲 |
| UI-04 | Promise拒绝、非法结构、响应超时 | 可见错误，无内部异常原文；历史信息标记非最新 |
| UI-05 | 点击刷新、重复ready事件、长请求、销毁后响应 | 不重叠请求，不保留监听或定时器，不写回迟到响应 |
| UI-06 | 结果含HTML、长任务名、null返回值 | 文本转义，布局不溢出，结果不过度渲染 |
| UI-07 | 构建/浏览器验证 | 依赖锁定、类型和组件测试通过，输出离线资源 |

组件测试只模拟 pywebview 桥这一外部边界；Python worker 生命周期、真实 Windows 窗口和现场兼容性由主任务集成验证，不能凭本目录单测判定通过。

## 命令

在本目录执行：

```text
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

可选浏览器验证（本机需已安装 Python Playwright 和 Microsoft Edge）：

```text
python -B -X utf8 scripts/verify-browser.py
```

它仅启动回环地址的临时静态服务器和独立无头 Edge，结束后自动关闭；测试快照通过桥边界注入，不进入应用打包文件。截图与结果存入 `verification/`，实际执行记录见 [验证报告](verification/report.md)。

构建先输出本目录 `dist/`，验证目标路径后发布到 `../src/autojobs_agent/desktop_assets/`。该生成目录专供当前窗口使用；不修改其他应用输出。宿主应读取其中的 `index.html`，而不是连接开发服务器或 CDN。

开发预览 `pnpm dev` 未注入本机桥时会显示“请从执行端打开此窗口”，不会用假快照填充页面。UI 状态词和日期格式由本目录单一映射定义。
